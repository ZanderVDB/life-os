What changed in the modal:
• Pin toggle at the top-right of the modal — pin/unpin from inside the detail view.
• Tags section — current tags + a "+ Tag" pill that opens a tag picker (existing tags) or lets you create a new one inline.
• Level widget: (1) Shows current position as "L4.3 · Close friend (3/5)" with a 25-slot bar visualising the position. (2) Up/down arrows nudge by one slot at a time, crossing level boundaries as needed (e.g. L4.5 ▲ → L5.1). (3) Below: the 5 named-level picker — tap a level to jump there. Default sub-position when jumping = 3 (middle). (4) Sub-positions don't have names — just numbers — matching your spec.
• Promises is now a list, not a single field. Each row: text, [link/linked badge], [edit pencil], [delete trash]. "+ Add another promise" at the bottom. Linked promises show a green "🔗 Linked" badge instead of the action button.
• Edit (pencil) turns the row into an inline editor for text + optional date. Save / cancel inline.
• Last did together stays a single slot — only the most recent completion is remembered. Matches your "no history" rule.

Final v1 scope summary

In v1:
  • People grid (mobile + desktop), card shape per mockup
  • Multiple promises per person, with edit + delete + link-to-task
  • Manual level system — 5 levels × 5 sub-positions = 25 slots, up/down arrows, level picker
  • Customizable tags + level names in Settings → People
  • Pin button (always-on-top)
  • Last-seen badge (auto from lastTogether)
  • Birthday read-only from GCal, "+ Add birthday" opens GCal event creator
  • AI ops: addPerson, addPromise (with full review-queue support)
  • Sort by: promise date (default), level, last seen, name, recently added
  • Filter by tag
Out (per your call):
  • XP / gamified levels — manual only
  • Birthday surface on Daily (already covered by morning brief)
  • Photos
  • Drag-to-reorder cards (pin handles the same need)
  • Promise history (only "last did together" remembered)
Reply in terminal: say "go" to write the specs, or call out anything to tweak first. Habit popup design unchanged from the previous mockup — also included in the spec.
