My calls:
• Trigger: on app load, compare localStorage.los_habit_popup_lastShown with today's ISO date. If different (or unset), show the popup and update the flag. So it fires once per day, on first open, regardless of how many tabs/sessions you have.
• "Yesterday" = local-time yesterday. If you open the app for the first time on Wednesday morning, you see Tuesday's habits.
• Already-ticked items are pre-checked so you only need to add new ones, not re-tick what's already done.
• Rest days (per habit's excludedDays) appear greyed out but are still tickable as bonus ticks. Matches the existing habit-day modal behaviour.
• "Skip" closes without changes but still marks the popup as shown for today — won't re-pop later.
• "Done" commits any toggles and closes.
• Tapping outside the modal = same as Skip.
• If you have zero habits, the popup doesn't show at all — nothing to ask about.
• Reuses the existing openHabitDayModal() machinery with one extra setting to auto-show on first daily open. Tiny code surface.
