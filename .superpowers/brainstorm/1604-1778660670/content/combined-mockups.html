Calls inside the modal:
• Birthday is read-only — pulled from any GCal event matching "[Jack]'s birthday". If none found, row shows "+ Add birthday" → opens GCal event creator with prefilled all-day yearly event. GCal stays the single source of truth.
• Friendship level — needs your decision:
   (a) Manual — you pick 1-5 yourself. Honest, no gamification.
   (b) XP-based — auto-levels as you complete promises (L2 at 1, L3 at 3, L4 at 7, L5 at 15). I lean (b) — you said "leveling system could be fun".
• Link to task creates a task on Daily with text "Jack: Go for coffee" and a back-link to Jack. Ticking the task → promise moves to "Last did together" + task disappears.
• Only ONE promise + ONE last-did-together per person. No history. Matches your spec.

Suggestions worth considering (your call — pick which to include)

S1 · "Last seen N days ago" badge. Auto-computed from when you completed your last promise. After 90+ days, card tints soft red — "you owe this person."
S2 · Tags / groups. Tag people as "uni friends", "work", "family" — quick filter chips above the grid.
S3 · AI hook. Add addPerson + addPromise ops so you can say "remind me Jack and I said we'd grab coffee" and it lands on his card.
S4 · Birthday surface on Daily. When a tracked person's birthday hits, surface a "Wish Jack happy birthday" suggestion on the Daily tab.
S5 · Drag-to-reorder cards. Like the Areas tab — pin your inner circle at the top regardless of sort.
S6 · Skip the level system entirely. Cleaner, less to maintain — "last seen" badge does the same job.
My recommended cut for v1: S1 + S3 + S4 + manual level (or XP — your call). Skip S2 (revisit if you hit 50+ people). Skip S5 (default sort handles it).

My calls:
• Trigger: on app load, compare localStorage.los_habit_popup_lastShown with today's date. If different, show + set flag. Fires once per day, on first open, regardless of how many sessions.
• "Yesterday" = local-time yesterday. Open the app first thing Wednesday morning, you see Tuesday's habits.
• Already-ticked items pre-checked so you only add what's new.
• Rest days (per habit's excludedDays) appear greyed but still tickable as bonus. Matches existing habit-day modal.
• Skip closes without changes but marks popup shown for today — won't re-pop.
• Tap outside = same as Skip.
• No habits yet? Popup doesn't show — nothing to ask.
• Settings toggle "Daily habit catch-up" — on by default, can be flicked off.
• Reuses existing openHabitDayModal() machinery with auto-show. Tiny code surface.
