Check for updates
Force a check if the update toast hasn't appeared.
Force update
Nuclear option — unregisters the service worker, clears all cached assets, and reloads from the network. Use this if the Relaunch button isn't working (typically iOS Safari clinging to a stale cached version).
Reset device state
Sign out, wipe ALL local storage (auth, cache, IndexedDB, service worker), and reload. Use only if the app is genuinely stuck in a broken state (login loops, phantom popups, sync that won't settle). Your data on Firestore is untouched — you'll need to sign in again to load it.
Diagnostic log
View the last few hundred console messages from this session. Useful for debugging — every console.log / warn / error gets captured in a ring buffer so you can read it on phone without dev tools.
