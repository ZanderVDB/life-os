# Library — starter Books

**A new Library is not an empty room.**

## The problem

The shelf is drawn furniture: a back panel, uprights, a ledge, a cast shadow.
Drawn furniture with nothing on it does not read as "your Library is new". It
reads as *something failed to load*.

An empty state that explains itself in a sentence is worse still, because the
first thing the Library would ever say is an apology.

## The three

| Book | subtitle |
|---|---|
| **Notes** | Anything worth keeping |
| **Ideas** | Before they are decisions |
| **Learning** | What you are working through |

Three because it is enough to show what a shelf is and few enough that it is
obviously a starting point rather than someone else's filing system. Each is a
real, empty, editable, deletable Book — not a placeholder, not a template, not
a tour card. If you rename one it stays renamed; if you delete all three you get
an empty shelf, which by then is a shelf you emptied.

All three come out at the **minimum thickness, 26px**, because they have nothing
in them yet. That is the point: they get visibly fatter as you write. The first
time a starter Book is thicker than the one beside it, the shelf has started
telling you something true about your own work.

Their heights still vary, from their ids, so the row is not three identical
rectangles.

## What this costs

Measured at 1280: three starter Books occupy 116px of an 897px shelf,
left-aligned. The shelf is 87% empty, and it should be — nothing stretches to
fill it, because a Book that changes width with the collection size means
nothing. A sparse shelf with three real Books on it is honest; a stretched one
is a lie about how much you have.

## The Diary

The Diary is created for every workspace regardless, and it stands first. So the
true first-run shelf is **four** Books: the Diary and the three starters.
